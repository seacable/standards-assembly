# 标准汇编生成工具包 / Standards Assembly Toolkit

> 把散落在各网站的行业标准、资质标准、法规文件，一键汇编成**带三级导航、速查表、附件还原、现行性核验**的单文件 HTML 与 PDF。

本仓库包含两个部分：

1. **成品汇编**（`dist/`）——《建筑业资质标准汇编》v1.0，收录施工/设计/监理/勘察/测绘/公路养护/房地产开发/城乡规划/地质灾害 9 大类共 105 篇现行标准及全部附件（103 个附件：85 个表格 + 172 张图片），可直接下载使用。
2. **汇编制作技能**（`SKILL.md` + `scripts/`）——沉淀自 12 个版本迭代的完整制作方法论，供 AI 编程助手（Trae / Claude 等 Skills 兼容环境）复用，用来制作任何领域的标准汇编（如采购法规汇编、医疗规范汇编等）。

## 成品特性

- **105 篇 / 10 卷**：12 项施工总承包＋36 项专业承包＋劳务＋设计 21 行业 7 专项＋监理/勘察/测绘/养护/房开/规划/地灾＋配套政策 5 件
- **附件完整还原**：Excel 配备表/规模划分表（含合并单元格、斜线表头）、Word 全文、PDF 部令逐页渲染、RAR 内附表截图，共 85 表 + 172 图
- **三层导航**：总目录 → 本卷速查表 → 具体/附件，全部双向跳转；每页右上角“主页/目录/本卷/本文”链接组
- **增值汇总表**：49 项承包工程范围一览、27 篇设计业务范围一览、10 卷速查表
- **现行有效性核查表**：三轮交叉核验（源网站标注 → 部委官网文件库 → 地方核查通知依据清单），注明核验日期与后续修订警示
- **PDF 工程化**：双遍构建（锚点页码 + 右上角链接组）、跳转保持缩放、书签大纲；可选 45° 平铺水印与权限加密

## 目录结构

```
├── SKILL.md              # 汇编制作技能（AI 可直接加载执行）
├── scripts/              # 参考实现（Python）
│   ├── parse_attach.py   #   附件解析：xls(含合并单元格/斜线表头)/docx/pdf/rar → 数据块
│   ├── build_html.py     #   数据 → 单文件 HTML（目录/速查表/水印可选）
│   ├── build_pdf.py      #   数据 → PDF（双遍构建/链接组/水印/加密可选）
│   └── supplement_attach.py  # 附件块合并进正文数据
├── dist/                 # 成品汇编 v1.0（无水印无加密公开版）
└── README.md
```

## 快速开始

**方式一：直接使用成品**
下载 `dist/` 下的 HTML（浏览器打开）或 PDF（517 页），即可使用全部导航功能。

**方式二：用技能制作自己的汇编**
把 `SKILL.md` 放入 AI 助手的技能目录（如 Trae 的 `.trae/skills/` 或 Claude 的 skills 目录），然后对 AI 说：

> “帮我把 XX 标准汇编网站做成一份汇编，目录放前面，附件全部保留，做成 HTML 和 PDF。”

AI 会按 SKILL.md 的十步流程完成：范围确认 → 数据建模 → 正文与附件抓取 → 速查表与汇总表 → HTML/PDF 生成 → 现行性核验 → 版本化交付。

**方式三：参考脚本自行改造**
`scripts/` 中的脚本以本项目（建筑业资质）为参考实现，数据模型见 SKILL.md 中的 schema 说明，替换数据源即可适配任意领域。

可选配置（环境变量，默认均关闭）：

| 环境变量 | 作用 |
|---|---|
| `ASM_WATERMARK` | 设置后 HTML/PDF 加 45° 平铺文字水印；留空则无水印 |
| `ASM_PDF_PWD` | 设置后 PDF 加密并禁止打印/修改/复制/批注；留空则不加密 |

示例（PowerShell）：`$env:ASM_WATERMARK='水印文字'; python scripts/build_pdf.py`

## 现行性核验方法（三轮交叉）

1. **第一轮**：源网站各分类所标版本；
2. **第二轮**：部委官方网站文件库/规章库逐项核对文号、施行日期与有效性（住建部、自然资源部、交通运输部、中国政府网）；
3. **第三轮**：地方住建部门年度资质核查通知所列现行依据清单、自然资源部法规库“现行有效”标注交叉印证。

> 本汇编核验日期：2026-09-30（I 版）。政策以官方最新发布为准，建议每月核验一次。
